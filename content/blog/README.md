# 먹맵 블로그 글 쓰는 법

mukmap.kr/blog 에 올라가는 글입니다. 파일 하나가 글 하나입니다.

## 파일

- 위치: `content/blog/<slug>.md`
- slug는 영어 소문자·숫자·하이픈만 씁니다(예: `tzuyang-october-places`). 주소가 `/blog/<slug>`가 됩니다.
- `_`로 시작하는 파일과 이 README는 올라가지 않습니다. 초안은 `_draft-xxx.md`로 두세요.

## 머리말 (맨 위, 필수)

```
---
title: 유튜버 3명 이상이 따로 다녀간 집 7곳
description: 검색 결과에 나오는 한두 문장(40~160자).
date: 2026-10-24
updated: 2026-10-24
tags: 쯔양, 서울 맛집, 노포
---
```

- `title`, `description`, `date`는 꼭 넣습니다. `updated`는 고쳤을 때만 바꿉니다.

## 본문에 쓸 수 있는 것

- `## 소제목`, `### 작은 소제목`
- 빈 줄로 문단을 나눕니다.
- `- ` 목록
- `**굵게**`, `[글자](/youtuber/쯔양)` 링크
- `[[가게:385]]`: 한 줄에 단독으로 씁니다. 가게 카드(썸네일·지역·다녀간 유튜버·먹은 것)로 바뀌고 `/restaurant/385`로 이어집니다.
- `[[유튜버:쯔양]]`: 유튜버 페이지 링크로 바뀝니다(이름 또는 slug).
- `[[숫자:가게]]`, `[[숫자:유튜버]]`, `[[숫자:지역:부산]]`, `[[숫자:유튜버가게:쯔양]]`: 지금 DB 숫자로 바뀝니다. 글에 숫자를 박지 말고 이걸 쓰세요.

## 소재 찾기 (데이터)

- 전체 가게: `curl -s https://mukmap.kr/api/pins` → `pins[]`에 id, name, region, city, category, menu, price, verdict, nv(영상 수), ch(유튜버 번호 → `channels[]`).
- 가게 하나 자세히: `https://mukmap.kr/restaurant/<id>`
- 소재 예: 여러 유튜버가 따로 간 집, 지역별 가장 많이 간 곳, 같은 메뉴(냉면·국밥) 모음, 1만 원 이하 가성비, 유튜버별 이번 달 간 곳(`/youtuber/<이름>/new`).

## 쓰는 규칙

- 질문형 소제목(`~은?`) 바로 아래 첫 문장에 답을 씁니다. AI 검색이 그 문장을 인용합니다.
- 사실만 씁니다. 맛 평가는 영상 속 유튜버의 말로 옮깁니다.
- 가게 카드는 글 하나에 3~10개가 적당합니다.

## 올리기

```
bash scripts/blog_publish.sh content/blog/<slug>.md
```

- 머리말·slug·가게 id·유튜버 이름을 검사하고, 그 파일만 커밋·푸시하고 배포합니다.
- 검사에 걸리면 아무것도 올리지 않습니다.
